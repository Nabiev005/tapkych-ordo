# 🏆 Тапкыч ордо

«Акыл ордо» форматындагы интеллектуалдык оюн платформасы.

- **Алып баруучу** оюнду ноутбуктан башкарат.
- **Суроолор** жалпы экранга (проекторго) чыгат.
- **Оюнчулар** өз телефондорунан А / Б / В / Г баскычтарынын бирин басышат.
- Ким туура, ким ката жооп бергени аты-жөнү менен реалдуу убакытта көрүнөт.

Интернет **милдеттүү эмес**: ноутбук менен телефондор бир Wi-Fi тармагында болсо жетиштүү.

## 1. Тез баштоо (Windows)

1. [Node.js](https://nodejs.org) программасынын **LTS** версиясын (20 же андан жогору) орнотуңуз.
2. `тапкыч` папкасындагы **`ИШТЕТҮҮ.bat`** файлын эки жолу басыңыз.
   - Биринчи жолу ал керектүү файлдарды орнотот (интернет керек, бир нече мүнөт кетет).
   - Андан кийин ар бир иштеткенде дароо ачылат.
3. Браузерде алып баруучунун панели ачылат: `http://localhost:3000/admin`
   - Логин: **`admin`**
   - Пароль: **`ordo2026`**

> ⚠️ Биринчи оюнга чейин паролду сөзсүз өзгөртүңүз: `server/.env` файлын Блокнот менен ачып, `ADMIN_PASS=` деген саптагы паролду алмаштырыңыз.

> ❗ Оюн бүткүчө кара терезени (сервердин терезесин) **жаппаңыз**.

## 2. Кол менен орнотуу

Бул бөлүм Windows, macOS жана Linux үчүн бирдей.

```bash
# 1. Жөндөөлөр файлын түзүү
cp server/.env.example server/.env        # Windows: copy server\.env.example server\.env

# 2. Баарын бир буйрук менен орнотуу: пакеттер, база, 25 мисал суроо, build
npm run setup

# 3. Иштетүү
npm start
```

Сервер ушул даректерде ачылат:

| Ким үчүн | Дарек |
|---|---|
| Алып баруучу | `http://localhost:3000/admin` |
| Жалпы экран | алып баруучунун панелиндеги «Жалпы экранды ачуу» баскычы |
| Оюнчулар | `http://<ноутбуктун-IP>:3000/join`. Бул дарек жана QR-код экранда жана PIN карточкаларында көрсөтүлөт. |

## 3. Оюнду кантип өткөрүү керек — алып баруучу үчүн

### Оюнга чейин

1. **Суроолорду даярдаңыз.** «Суроолор» бөлүмүнөн суроолорду бирден кошсоңуз болот, же «Excel/CSV'ден импорттоо» аркылуу файлдан жүктөсөңүз болот.
   - Ар бир турда суроо жетиштүү экени жашыл ✓ белгиси менен көрсөтүлөт: 1-турда 10, 2-турда 10, финалда 5.
   - Суроолордун тартибин ⠿ белгисинен кармап сүйрөп өзгөртүңүз.
2. **«Жаңы оюн түзүү»** баскычын басып, 12 оюнчунун аты-жөнүн ар бир сапка бирден жазыңыз.
3. **PIN карточкаларын басып чыгарыңыз** («PIN'дерди басып чыгаруу» баскычы). Ар бир оюнчуга өзүнүн карточкасын жеке бериңиз.
4. Проекторго туташкан браузерде **«Жалпы экранды ачуу»** баскычын басып, **F11** менен толук экранга өткөрүңүз.
   - Үн чыгышы үчүн экранды бир жолу чычкан менен басыңыз.

### Оюн учурунда

Оюнчулар телефондон QR-кодду сканерлеп же даректи жазып, **кошулуу коду + өз PIN'и** менен киришет. Ким кошулганы панелде жашыл түс менен белгиленет.

**«ОЮНДУ БАШТОО»** баскычын басканда оюн башталат. Андан кийин эң чоң **«Кийинки кадам»** баскычын баса бериңиз, ал ар дайым кийинки туура аракетти көрсөтөт:

```
Биринчи суроо → Суроону көрсөтүү (таймер башталат) → Туура жоопту ачуу → Кийинки суроо → …
… → Турду аяктоо → өткөндөрдү текшерип ырастоо → кийинки тур → … → Оюнду аяктоо
```

- **Рейтинг** — каалаган учурда экранга упайлар таблицасын чыгарат.
- **Тыныгуу** — оюнду токтотот. Суроо жүрүп жатса, таймер да токтойт.
- **Суроону кайра баштоо** — техникалык көйгөй болсо, суроого берилген жооптор өчүрүлүп, суроо кайра башталат.
- **± Упайды оңдоо**, **⛔ Оюндан чыгаруу** — оң жактагы оюнчулар тизмесинде.
- Маанилүү аракеттердин баары адегенде ырастоону сурайт, ошондуктан кокус басып алсаңыз коркпоңуз.

### Окуучулар, архив, тарых жана рейтинг

- **Окуучулар.** Окуучулардын туруктуу тизмеси аты-жөнү жана классы менен сакталат. Тизмени бирден же «Аты-жөнү; классы» форматында бир нече сап менен кошсо болот. Оюн түзгөндө катышуучулар ушул тизмеден тандалат.
- **Архив.** Оюнда суралган ар бир суроо автоматтык түрдө «Архив» өтмөгүнө өтөт. Ошондуктан кийинки оюнда ал кайталанбайт. Архивден суроону кайра банкка кайтарса болот: бирден, же бир нечесин чогуу «Баарын банкка кайтаруу» баскычы менен.
- **Тарых.** Аяктаган бардык оюндар сакталат: аталышы, датасы, жеңүүчүлөрү, суралган суроолору жана Excel файлы.
- **Рейтинг.** Бардык оюндар боюнча эң акылдуу окуучулардын тизмеси `/rating` дарегинде турат. Бул ачык бет, аны проекторго да чыгарса болот.
  - Иреттөө: жалпы упай → жеңиштер → туура жооптордун пайызы.
  - Класс боюнча чыпкаласа болот.
  - Алып баруучу рейтингди Excel файлга жүктөп ала алат.

### Суроолордун түрлөрү, темалар жана кыйынчылык

- **Үч түр:**
  - **Тандоо** — А/Б/В/Г;
  - **Туура / Туура эмес** — эки чоң баскыч;
  - **Иретке келтирүү** — оюнчу 4 элементти туура тартипте басат.
- Ар бир суроого **тема** (мис. «Тарых») жана **кыйынчылык** (Жеңил / Орто / Кыйын) берилет.
- **Сүрөт** жүктөлгөндө автоматтык түрдө кичирейет.
- Музыкалык суроолор үчүн **аудио** кошсо болот. Ал экранда өзү ойнойт.
- **Excel'ге жүктөө** — банк жана архив бир файлга сакталат. Ал резервдик көчүрмө катары колдонулат, ошондой эле башка мугалим менен бөлүшсө болот. Файлды кайра импорттосо болот.

### Оюндун режимдери (оюн түзүүдө)

- **Класс класска каршы.**
  - Команда — окуучунун классы.
  - Эч ким чыгарылбайт, команданын упайы мүчөлөрүнүн упайларынын суммасы.
  - Экранда командалардын рейтинги жана жеңүүчү команданын пьедесталы көрсөтүлөт.
- **Ылдам жооп бонусу** — туура жоопту убакыттын алгачкы үчтөн биринде берген оюнчуга кошумча упай (⚡+1) берилет.
- **«50/50»** — ар бир оюнчу бир оюнда бир жолу эки ката вариантты өчүрө алат.
- **Суроолорду тандоо:**
  - турлар боюнча, банктагы тартипте;
  - же кыйынчылык боюнча: 1-тур жеңил, 2-тур орто, финал кыйын.
- **Темалар** — оюнга тандалган темалардагы суроолор гана алынат.
- **Залдагы көрүүчүлөр.** Экранда экинчи QR-код бар (`/watch/КОД`). Залдагылар PIN'сиз эле добуш берет, ал эми туура жооп ачылганда экранга «Залдын 80%ы А вариантын тандады» деген сыяктуу жыйынтык чыгат. Добуштар упайга таасир этпейт.
- **Оюнду кайталап көрүү** — оюн бүткөндөн кийин ар бир суроону, ким кандай жооп бергенин жана рейтингдин өзгөрүшүн ← → баскычтары менен кадам-кадам көрсө болот.

### Мугалимдер, сезондор, грамоталар

- **Мугалимдер** (башкы алып баруучу гана кошот).
  - Ар бир мугалим өз логини менен кирет.
  - Ар биринин өзүнүн суроолор банкы, оюндары жана тапшырмалары болот.
  - Окуучулар тизмеси жана рейтинг — жалпы.
- **Сезондор.**
  - Рейтингди мезгилдерге бөлсө болот (мис. «Күзгү сезон 2026»).
  - Рейтинг бетинде сезон тандалат.
- **Грамоталар.**
  - Сезондун же бардык убакыттын алдыңкы үчтүгү үчүн даяр, оюу-оймолуу грамоталар түзүлөт.
  - Аларды «Басып чыгаруу → PDF катары сактоо» аркылуу PDF файл кылса болот.
- **Окуучунун жеке баракчасы.** Рейтингде атын басканда ачылат. Анда:
  - медалдар;
  - упайдын өсүш графиги;
  - темалар боюнча тактык жана эң күчтүү тема;
  - катышкан оюндар жана тапшырмалар.

### Үй тапшырмасы

1. **Тапшырмалар → Жаңы тапшырма** баскычын басыңыз. Суроолор автоматтык түрдө (тема жана кыйынчылык боюнча) же банктан колго тандалат.
2. Шилтемени (`/hw/КОД`) же QR-кодду окуучуларга жибериңиз.
3. Окуучу классын жана атын тандап, суроолорго жооп берет. Ар бир суроонун убактысы сервер боюнча эсептелет, ошондуктан баракты жаңыртып убакыт утуп алууга болбойт.
4. Мугалим жыйынтыктарды реалдуу убакытта көрөт:
   - Excel'ге жүктөп алса болот;
   - тапшырманы жаап же кайра ачса болот;
   - окуучуга кайра иштөөгө уруксат берсе болот.

   Жыйынтыктар рейтингге кошулат.

### Тил

Бардык беттердин жогору жагында **КЫР / РУС** которгучу бар. Тандалган тил ар бир түзмөктө өзүнчө сакталат. Тексттер: `client/src/i18n/ky.ts` жана `client/src/i18n/ru.ts`.

### Оюндан кийин

Экранга пьедестал жана конфетти чыгат. Пьедесталды эки жолу басканда жалпы таблица көрүнөт. Панелдеги **«Толук жыйынтыкты Excel'ге жүктөп алуу»** баскычы ар бир суроо боюнча ким кандай жооп бергенин камтыган файлды жүктөйт.

> 💡 Ноутбуктун браузери кокус жабылып же жаңыланып кетсе, оюн серверде уланып жатат. Панелди кайра ачсаңыз, ошол эле жерден уланасыз. Телефондун байланышы үзүлсө да, оюнчу ошол эле абалына жана упайына кайтат.

## 4. Wi-Fi жана брандмауэр

- Ноутбук жана оюнчулардын телефондору **бир эле Wi-Fi тармагында** болушу керек.
- Сервер биринчи жолу иштегенде Windows «Брандмауэр» терезеси чыгат. **«Жеке тармактар»** (Private networks) деген белгини коюп, **«Уруксат берүү»** баскычын басыңыз.
- Телефондор кире албай жатса:
  1. Ноутбуктун Wi-Fi тармагы «Жеке» (Private) деп коюлганын текшериңиз: *Жөндөөлөр → Тармак → Wi-Fi → Касиеттер*.
  2. Кафе же мейманкана Wi-Fi'ы түзмөктөрдүн бири-бирине туташуусуна бөгөт коюшу мүмкүн («client isolation»). Андай болсо өзүңүздүн роутериңизди колдонуңуз же телефондон хот-спот түзүңүз.
- Ноутбуктун IP дареги сервердин терезесинде «Тармакта: http://192.168…» деп жазылат.

## 5. Серверге (интернетке) жайгаштыруу

### 5.0. Vercel + Render (акысыз)

Сайттын сырткы бети **Vercel**’де, ал эми сервер жана база **Render**’де турат. Vercel өзү Socket.IO серверин жана SQLite базасын иштете албайт, ошондуктан сервер Render’ге коюлат.

> ⚠️ **Render’дин акысыз планынын чектөөлөрү:**
> - 15 мүнөт колдонулбаса, сервер уктап калат. Андан кийинки биринчи ачылышы ~1 мүнөткө созулат, ошондуктан оюндан мурун сайтты алдын ала ачып коюңуз.
> - Turso туташтырылбаса, сервер кайра иштетилгенде база тазаланат. Ошондуктан **3-кадамды (Turso) сөзсүз аткарыңыз**: ошондо суроолор, сүрөттөр, окуучулар, оюндардын тарыхы жана рейтинг туруктуу сакталат.

**1-кадам — Render (сервер):**
1. [render.com](https://render.com) сайтына GitHub аккаунту менен кириңиз.
2. **New → Blueprint** баскычын басып, ушул репозиторийди тандаңыз. Render `render.yaml` файлын өзү окуйт.
3. `ADMIN_PASS` деген талаага алып баруучунун жаңы паролун жазыңыз да, **Apply** баскычын басыңыз.
4. Жайгаштыруу бүткөндө `https://tapkych-ordo-xxxx.onrender.com` сыяктуу дарек берилет. Аны көчүрүп алыңыз.
5. Текшерүү: `https://…onrender.com/api/health` дареги `{"ok":true}` деп жооп бериши керек.

**2-кадам — Vercel (сайт):**
1. [vercel.com](https://vercel.com) сайтына GitHub аккаунту менен кириңиз. **Add New → Project** баскычын басып, ушул репозиторийди тандаңыз.
2. **Root Directory** талаасына **`client`** деп жазыңыз.
3. **Environment Variables** бөлүмүнө:
   - аты: `VITE_API_URL`
   - мааниси: Render берген дарек (мисалы, `https://tapkych-ordo-xxxx.onrender.com`, аягында `/` белгиси жок)
4. **Deploy** баскычын басыңыз. Сиздин шилтемеңиз `https://<долбоор>.vercel.app` болот.
   - Алып баруучу: `https://<долбоор>.vercel.app/admin`
   - QR-код жана PIN карточкалары Vercel даректи автоматтык түрдө көрсөтөт.

**3-кадам — Turso (маалыматты туруктуу сактоо, акысыз):**
1. [turso.tech](https://turso.tech) сайтына GitHub аккаунту менен кириңиз.
2. **Create Database** баскычын басыңыз. Аты: `tapkych-ordo`, аймак (region): жакын жерди тандаңыз, мисалы Frankfurt.
3. Базанын бетинен **URL** дарегин көчүрүңүз. Ал `libsql://tapkych-ordo-….turso.io` сыяктуу болот.
4. **Create Token** баскычын басып, токенди көчүрүңүз. Аны эч кимге көрсөтпөңүз.
5. Render'де **tapkych-ordo → Environment** бөлүмүнө өтүп, эки өзгөрмө кошуңуз:
   - `TURSO_DATABASE_URL` = көчүргөн дарек
   - `TURSO_AUTH_TOKEN` = көчүргөн токен
6. **Save, rebuild, and deploy** баскычын басыңыз. Логдо `✓ Turso базасы даяр` деген жазуу чыкса, иш бүттү.

GitHub’га жаңы коммит жөнөтүлгөн сайын, экөө тең автоматтык түрдө жаңыланат.

### 5.1. Өзүнчө VPS (маалымат туруктуу сакталат)

Төмөндөгү мисал **Ubuntu 22.04/24.04** серверинде (VPS), домен менен жайгаштыруу үчүн.

#### Node.js жана долбоор

```bash
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs git

git clone <репозиторий> /opt/tapkych   # же файлдарды scp менен көчүрүңүз
cd /opt/tapkych
cp server/.env.example server/.env
nano server/.env      # ADMIN_PASS, JWT_SECRET жана PUBLIC_URL=https://ordo.example.kg
npm run setup
```

#### Туруктуу иштетүү (pm2)

```bash
sudo npm install -g pm2
pm2 start npm --name tapkych -- start
pm2 save
pm2 startup        # көрсөтүлгөн буйрукту аткарыңыз — сервер кайра күйгөндө оюн өзү иштейт
```

#### Nginx + HTTPS

```nginx
# /etc/nginx/sites-available/tapkych
server {
    server_name ordo.example.kg;
    client_max_body_size 10m;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        # Socket.IO (реалдуу убакыт) үчүн милдеттүү:
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;  # жана .env: TRUST_PROXY=1
        proxy_read_timeout 3600s;
    }
}
```

```bash
sudo ln -s /etc/nginx/sites-available/tapkych /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d ordo.example.kg
```

> `PUBLIC_URL` коюлса, QR-код жана PIN карточкалары ошол даректи көрсөтөт.

#### Жаңыртуу жана резервдик көчүрмө

```bash
cd /opt/tapkych && git pull && npm run setup && pm2 restart tapkych
```

Бардык маалымат (суроолор, сүрөттөр, окуучулар, оюндар, жыйынтыктар) **`server/prisma/dev.db`** файлында сакталат. Резервдик көчүрмө үчүн ушул бир файлды көчүрүп коюу жетиштүү.

## 6. Жөндөөлөр (.env)

`server/.env` файлы:

| Өзгөрмө | Демейки | Маанилүүлүгү |
|---|---|---|
| `PORT` | `3000` | Сервердин порту |
| `DATABASE_URL` | `file:./dev.db` | SQLite базасынын файлы |
| `ADMIN_USER` | `admin` | Алып баруучунун логини |
| `ADMIN_PASS` | `ordo2026` | Алып баруучунун пароли. **Сөзсүз өзгөртүңүз!** |
| `JWT_SECRET` | — | Кирүү токендери үчүн купуя сап. Узун, кокус сап жазыңыз. |
| `PUBLIC_URL` | бош | QR-кодго жазыла турган сайттын дареги. Бош калса, ноутбуктун IP'си же сайттын өз дареги колдонулат. |
| `TURSO_DATABASE_URL` | бош | Turso базасынын дареги (`libsql://…`). Коюлса, маалымат интернеттеги туруктуу базада сакталат. |
| `TURSO_AUTH_TOKEN` | бош | Turso токени |
| `TRUST_PROXY` | бош | Прокси (Render, nginx) артында иштесе `1` коюңуз. Ошондо PIN бөгөтү ар бир түзмөккө өзүнчө иштейт. |

Ар бир оюндун жөндөөлөрү оюнду түзүүдө коюлат:

| Жөндөө | Демейки |
|---|---|
| Туура жооп үчүн упай | 1 |
| Ар бир суроого убакыт | 15 сек |
| Турлардагы суроолордун саны | 10 / 10 / 5 |
| Кийинки турга өтүүчүлөр | 6 жана 3 |
| Күтүлгөн оюнчулар | 12 |

## 7. Суроолорду Excel/CSV файлдан импорттоо

Панелдеги «Импорттоо» бетинен **шаблонду жүктөп алыңыз** (.xlsx же .csv). Файлдын мамычалары:

| Тур | Суроо | А | Б | В | Г | Туура жооп | Сүрөт шилтемеси |
|---|---|---|---|---|---|---|---|
| 1 | Кыргызстандын борбор шаары кайсы? | Ош | Бишкек | Каракол | Нарын | Б | |
| Финал | «Кутадгу билиг» чыгармасынын автору ким? | … | … | … | … | Б | |

- **Тур:** `1`, `2` же `Финал`.
- **Туура жооп:** `А`, `Б`, `В` же `Г`. Латын тамгалары `A`/`B`/`C`/`D` да кабыл алынат.
- **Сүрөт шилтемеси:** милдеттүү эмес. Сүрөттү суроону оңдоо терезесинен компьютерден жүктөсөңүз оңой.
- Импорттон мурун система файлды текшерип, каталуу саптарды номери менен көрсөтөт.

## 8. Оюндун эрежелери

| | 1-тур | 2-тур | Финал |
|---|---|---|---|
| Оюнчулар | 12 | 6 | 3 |
| Суроолор | 10 | 10 | 5 (алып баруучу өзгөртө алат) |
| Убакыт | 15 сек | 15 сек | 15 сек |
| Кийинки турга | эң мыкты 6 оюнчу | эң мыкты 3 оюнчу | 1-2-3-орундар |

- Туура жооп = 1 упай. Ката же жооп бербесе = 0 упай.
- **Ар бир турда упай нөлдөн башталат.** Кийинки турга өтүү ошол турдун упайы менен аныкталат. Жалпы жыйынтыкта бардык турлардын упайы көрсөтүлөт.
- **Упайлар тең чыкса**, жоопторго жалпы аз убакыт короткон оюнчу жогору турат. Жооп бербей калган суроо үчүн толук убакыт (15 сек) эсептелет.
- Упайы да, убактысы да **так** бирдей болсо, тизмеде «тең» деген белги чыгат. Ал учурда алып баруучу кимди өткөрөрүн кол менен тандайт.
- Тур аягында алып баруучу өткөндөрдүн тизмесин көрүп, ырастайт жана керек болсо кол менен оңдойт.
- **Жалпы орундар:** адегенде эң алыс жеткен тур эске алынат (финалисттер жогору турат), андан кийин ошол турдагы упай жана убакыт.

## 9. Коопсуздук

- **Жеке PIN:** ар бир оюнчуга 4 сандан турган жеке PIN берилет. Кошулуу коду экранда баарына көрүнгөнү менен, PIN'сиз эч ким кире албайт.
- **PIN тандоодон коргоо:** бир түзмөктөн 5 мүнөттүн ичинде 10 ката аракет болсо, ал түзмөк бөгөттөлөт. Бир оюнга бардык түзмөктөрдөн 60 ката аракет болсо, оюнга кирүү да убактылуу бөгөттөлөт.
- **Бир PIN — бир түзмөк:** ошол эле PIN менен экинчи телефондон кирилсе, биринчи телефон ажыратылат. PIN бөтөн адамга белгилүү болуп калса, панелден 🔄 баскычы менен оюнчуга жаңы PIN берсеңиз болот.
- **Жооптор серверде гана текшерилет.** Туура жооп «Туура жоопту ачуу» басылмайынча телефонго да, экранга да жөнөтүлбөйт. Суроонун тексти жана варианттары телефонго суроо экранга чыккан учурда гана жөнөтүлөт.
- **Таймер сервер боюнча эсептелет.** Убакыт бүткөндөн кийин келген жоопту сервер кабыл албайт.

## 10. Көйгөйлөр жана чечимдер

| Көйгөй | Чечим |
|---|---|
| «3000-порт бош эмес» | Сервер башка терезеде иштеп жатат. Ал терезени жабыңыз же `.env` файлында `PORT` маанисин өзгөртүңүз. |
| Телефон кире албайт | [4-бөлүмдү](#4-wi-fi-жана-брандмауэр) караңыз: тармак бирдейби, брандмауэр уруксат бердиби. |
| «PIN код туура эмес» | Кошулуу кодун жана PIN'ди текшериңиз. 10 ката аракеттен кийин 5 мүнөт күтүү керек. |
| Экранда үн жок | Экранды бир жолу басыңыз (браузерлер үндү ушундан кийин гана уруксат кылышат). Панелдеги 🔊 баскычы күйгүзүлгөнүн текшериңиз. |

| Паролду унуттум | `server/.env` файлындагы `ADMIN_PASS` маанисин караңыз же өзгөртүп, серверди кайра иштетиңиз. |

## 11. Иштеп чыгуучулар үчүн

### Технологиялар

- **Backend:** Node.js, Express 5, Socket.IO, Prisma 6, SQLite, ExcelJS
- **Frontend:** React 19, Vite, TypeScript, Tailwind CSS 4, Framer Motion, dnd-kit, qrcode.react, canvas-confetti
- **Шрифттер:** Montserrat жана Inter. Алар долбоордун ичинде жүрөт, ошондуктан интернетсиз да иштейт.
- **Үндөр:** Web Audio API аркылуу түзүлөт, үн файлдары керек эмес.

### Иштеп чыгуу режими

```bash
npm run dev        # сервер :3000 (tsx watch) + Vite :5173 (hot reload)
```

Бул режимде панел `http://localhost:5173/admin` дарегинде ачылат.

### Папкалардын түзүлүшү

```
тапкыч/
├─ ИШТЕТҮҮ.bat                 # Windows үчүн бир баскыч менен иштетүү
├─ server/
│  ├─ prisma/schema.prisma      # базанын схемасы
│  ├─ prisma/seed.ts            # 25 мисал суроо
│  └─ src/
│     ├─ game/engine.ts         # оюндун агымы, таймер, жооптор (бардык логика серверде)
│     ├─ game/scoring.ts        # упай, тең чыгуу эрежеси, жалпы орундар
│     ├─ game/state.ts          # ар бир ролго өзүнчө абал (туура жоопту жашыруу)
│     ├─ sockets/index.ts       # Socket.IO бөлмөлөрү жана авторизация
│     └─ routes/                # REST: суроолор, оюндар, импорт/экспорт, кирүү
└─ client/src/
   ├─ i18n/ky.ts                # ⭐ интерфейстин БАРДЫК тексттери
   ├─ pages/admin/              # алып баруучунун панели
   ├─ pages/player/             # оюнчунун телефону
   ├─ pages/screen/             # жалпы экран (проектор)
   └─ components/               # оюулар, баскычтар, таймер, рейтинг, пьедестал
```

### Тексттерди өзгөртүү

Интерфейстин бардык тексттери **`client/src/i18n/ky.ts`** файлында. Сервер тексттин ордуна ката кодун жөнөтөт (мисалы, `INVALID_PIN`), ал эми анын кыргызча котормосу ушул файлдын `errors` бөлүмүндө турат.

### Пайдалуу буйруктар

```bash
npm run db:seed --prefix server             # мисал суроолорду кошуу (база бош болсо)
npm run db:seed --prefix server -- --force  # бардык суроолорду өчүрүп, мисалдарды кайра жүктөө
cd server && npx prisma studio                 # базаны таблица түрүндө көрүү
```
